# Ataavi Corpus Forge

Engineering a production-ready bird knowledge corpus for future multimodal AI.

## Run locally

```bash
cd session4/web
npm install
npm run dev
```

## Build

```bash
cd session4/web
npm run typecheck
npm run build
```

## SpecKit

Feature: `specs/001-ataavi-corpus-forge`
