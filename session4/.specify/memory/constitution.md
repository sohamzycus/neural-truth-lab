# Session4 Constitution — Ataavi Corpus Forge

## P1 Story Over Dashboard
The app narrates corpus engineering end-to-end. It is an internal AI data portal, not an assignment checklist UI.

## P2 Data in JSON
All sample observations, stats, strategies, and charts load from `web/public/data/*.json`. No Lorem Ipsum. No hardcoded narrative paragraphs in components beyond structural labels.

## P3 Minimal Stack
Static Vite + React + TypeScript + Tailwind + Framer Motion. No backend, no auth, no live eBird API.

## P4 Domain Integrity
Bird examples are India-primary with a thin global slice. Conservation-sensitive GPS masking is explained, not glamorized.

## P5 Reproducible Demo
Dashboard metrics are curated. The scrub playground uses pure client transforms on a small sample set only.

## P6 Deployable
`session4/web` builds with Vite and deploys to Netlify via `netlify.toml`.
