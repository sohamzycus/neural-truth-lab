# Session3 Constitution — India-First 40B

## P1 Measured Truth
Every number in `report/` must trace to `data/derived/*.json`. Prose explains; Python computes.

## P2 Reproducibility
`python scripts/derive_all.py` regenerates all derived artefacts. SHA-256 manifests in `data/manifests/`.

## P3 Challenge Conventional Wisdom
Every major decision cites a quantitative counter-argument. Population-proportional mixing is rejected by default.

## P4 India-First
Language weights use deployment signals (internet presence, corpus availability, economic impact, demand), not census alone.

## P5 Minimal Stack
Python models + static Vite viewer. No CMS, no database, no runtime AI.

## P6 Chapter Template
Each chapter: Problem → Design Options → Pros/Cons → Decision → Rejected Alternatives → Expected Failure Modes → Decision Summary → Risks → Future Improvements.
