# Language Weights Spec

## Method

7-factor MCDA with sharpening exponent 2.8 on composite scores.

## Factors (weights on factors, not languages)

| Factor | Weight |
|--------|-------:|
| Internet presence (India) | 0.20 |
| Corpus availability | 0.20 |
| Economic impact | 0.15 |
| Deployment demand | 0.20 |
| Translation need | 0.10 |
| Code-switching | 0.10 |
| Government/education | 0.05 |

## Rejected

Population-proportional weighting (Hindi would be 39.2%).

## Outputs

`data/derived/language_weights.json`, `data/derived/data_mix.json`
